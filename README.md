# 大众点评探店笔记生产线 V4

把一家店的截图，加工成可以直接发到大众点评的图文。一家店出 1~2 份，图片和文案都整理好，你只需要在手机 App 里点发布。

**它不替你发布，也不改你的定位。** 这两件事始终在你自己手里。

---

## 装之前要有什么

| 需要 | 说明 |
| :--- | :--- |
| Windows 电脑 | 脚本是 Windows 批处理，macOS 需要手动敲命令 |
| Python 3.9+ | 安装时勾选“Add to PATH” |
| Google Chrome | 采集图片要用调试模式，登录一次即可 |
| 网络 | 能打开小红书页面 |
| 不需要 | 不需要 Node，不需要 Google 账号，不需要任何付费服务 |

依赖只有 5 个轻量包（Pillow、requests、websocket、numpy、opencv），装完约 120 MB。  
另有两个可选组件（文字过滤、人像过滤），装了更严，不装也能跑，具体见 `requirements.txt` 里的注释。

---

## 装（两步）

1. 双击 **`一键安装依赖环境.bat`**，它会检查 Python 并装三个依赖包。
2. 双击 **`启动Chrome调试模式.bat`**，在弹出的 Chrome 窗口里登录一次小红书，之后保持这个窗口开着。

装完可以双击 **`自检.bat`** 确认环境，缺什么它会直接说。

不想双击也行：把整个文件夹的路径交给你的 AI，说一句

```
这个文件夹是一套探店内容生产流程，请按 README 安装依赖，然后告诉我第一步怎么跑。
```

它会自己读说明、装依赖、带你跑。

---

## 跑（一次完整流程）

1. 把店铺截图（3~5 张）放进 `input/`。
2. 对 AI 说：`用这套流程处理 input 里的店铺，每家出 2 份笔记`。
3. 等它跑完，产出在 `当天日期/店铺名/笔记 1、笔记 2` 里。
4. 用手机取件工具（mobile-pickup）扫码，把图和文案拿到手机。
5. 打开大众点评 App，选图、贴文案、关联店铺、发布。

第一次建议先跑一家，确认产出没问题再批量。

## 它到底做了哪几件事

| 环节 | 干什么 | 谁来干 |
| :--- | :--- | :--- |
| 1 信息提取 | 从截图里读出店名、评分、推荐菜、套餐 | 脚本 + AI 读图 |
| 2 图片采集 | 按店名找实拍图，过滤头像、截图、大字报 | 脚本 |
| 3 图片处理 | 去重、拼图、生成九宫格 | 脚本 |
| 4 文案 | 写标题和正文，避开禁词 | AI 按规范写 |
| 5 封面 | 把九宫格叠上字体排版 | 脚本 |
| 6 送手机 | 扫码取图取文案 | mobile-pickup |
| 7 发布 | 选图、关联店铺、点发布 | **你本人** |

## 常见问题

**采集回来一堆头像和截图？**  
质检规则在拦，通常说明搜索词太宽。换成“店铺全名 + 分店名”再跑一次。

**只有 3~4 张图？**  
素材本来就少。可以补抓一次，或者把已有的图拼成更多海报——拼图环节会自动做。

**封面上的字变成方块？**  
字体文件丢了。检查 `ayi-store-note-cover-generator-v4/` 里四个 `.ttf` 是否齐全。

**文案读起来像广告？**  
重新让 AI 读一遍 `ayi-dianping-note-generator-v4/SKILL.md` 再写。那份规范里写了人设和禁词。

**能不能换封面引擎？**  
可以，这是可选的扩展。默认用本地拼图加字体排版，具体见 `plugins/README.md`。

## 边界

- 不代发，不模拟点击，不改定位。
- 采集的是公开页面上的实拍图，二次处理成新作品再用；直接搬原图会被平台判低质。
- 素材和文案只留在你自己电脑上，这套工具不上传任何数据。
