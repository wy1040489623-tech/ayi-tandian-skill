# 阿一多图智能无缝拼接 Skill (V4 旗舰版)

## 概述
本 Skill 专用于将指定文件夹内的美食/探店素材（优先读取 `P_` 高阶去重图）进行全自动、零白边、无缝隙的多图拼接处理，并自动生成 1 张 3×3 九宫格满铺封面图（`mix9_`）。

相较于早期版本清一色 4 拼图且数量较少的问题，**V4 版本实现三大核心突破**：
1. **多元拼图版式矩阵**：不仅有 4 拼图，全面引入【上下两拼】（50%/50%）与【上一下二三拼】（上面 1 个全宽、下面左右各一个），两拼、三拼、四拼均衡混搭；
2. **产出数量翻倍 (2x)**：内置智能多轮错位重排算法（默认 rounds=2），使有限素材输出的可用拼图数量较以前**增加一倍**；
3. **封面规范统一**：精确生成 1 张 3×3 九宫格无缝满铺图作为官方封面（`mix9_[商铺名].jpg`），完美衔接笔记封面发布需求。

## 核心输入参数规范

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| **`folder`** | string | 否 | `None` | 待处理图片所在文件夹的绝对路径（例如：`2026-10-15/聚宝源火锅/`） |
| **`batch_dir`** | string | 否 | `None` | 包含多个商铺子文件夹的父目录绝对路径（例如：`2026-10-15/`） |
| **`rounds`** | int | 否 | **`2`** | **拼图重组轮数**。默认 2 轮，直接让拼图产出总数量在原有基础上**翻倍** |
| **`note_count`** | int | 否 | **`1`** | **生成笔记的套数**。默认 1 套；指定为 2 或 3 时分别在“笔记 1”、“笔记 2”下生成互不相同的拼图组合 |

---

## 排版样式与布局规则

1. **2 拼图（上下两拼 `split_tb`）**：
   - 上半部分占 50% 高度（全宽 1080px × 720px）
   - 下半部分占 50% 高度（全宽 1080px × 720px）
   - 彻底摒弃呆板的左右细长窄屏对拼，上下构图更饱满诱人。

2. **3 拼图（上一下二 `top1_bottom2` 为主）**：
   - 上方：1 张全宽单图（1080px × 720px，展示主菜或全景）
   - 下方：左右 2 张各占 50% 宽度（540px × 720px，展示配菜/特写）
   - 配备辅助的“上二下一”（`top2_bottom1`），丰富排版节奏。

3. **4 拼图（田字四格 `grid_4`）**：
   - 2×2 田字无缝满铺，四格各占 25% 面积（540px × 720px）。

4. **九宫格封面（`mix9_`）**：
   - 提取 9 张精选菜品，3×3 无缝满铺（每格 360px × 480px）；
   - 精准生成 **1 张** 作为专属官方封面图。

## 执行流程与调用指南

Agent 在执行此 Skill 时，运行配套的 V4 专用驱动脚本：

```bash
# 1. 对单商铺执行 V4 拼图（2/3/4拼均衡混搭，数量翻倍，生成 1 张九宫格封面）
python food_collage_generator_v4.py --folder "<图片文件夹绝对路径>"

# 2. 批量处理父目录下所有商铺子文件夹
python food_collage_generator_v4.py --batch_dir "<日期父目录绝对路径>"

# 3. 生成多套互不相同的笔记拼图（例如 2 套）
python food_collage_generator_v4.py --folder "<图片文件夹绝对路径>" --note_count 2
```

## 输出产物清单与文件命名规范

所有产物均采用 1080×1440 高清竖屏比例（JPEG 95 高品质）：
- **九宫格封面图（1 张）**：**`mix9_[商铺名].jpg`**
- **多元拼接图海报（翻倍产出）**：**`mix_[商铺名]_[序号].jpg`**（例如 `mix_聚宝源火锅_1.jpg` ~ `mix_聚宝源火锅_12.jpg`）
