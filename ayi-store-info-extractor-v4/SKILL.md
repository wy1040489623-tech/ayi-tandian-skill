# 阿一商户信息获取 Skill (V4)

## 概述
本 Skill 专用于利用 AI 多模态视觉能力，深度解析用户提供的大众点评手机端商铺详情页截图（支持 1 张或多张截图，如首页、团购套餐页、推荐菜页等）。
作为 V4 统一版本体系的第 1 环节，由 AI Agent **直接使用视觉能力识别图片**，不仅能准确提炼基础商铺信息，更能高精度结构化提取**团购套餐现价/原价/立省金额**、**代金券专区（严格隔离）**、**网友推荐菜榜单与人数**、**人气打卡与订座热度**，输出标准化的《`店铺关键词.txt`》，并自动将原截图重命名归档至对应商铺目录下。

---

## 触发场景 (When to Use)
当用户提出以下需求时激活此 Skill：
- “从这张大众点评截图里提取店铺信息 (V4)”
- “解析店铺截图，提炼店铺关键词，包括团购和推荐菜 (V4)”
- “调用阿一商户信息获取 skill v4 处理图片”
- “看图提取商户信息并沉淀店铺关键词.txt”

## AI 视觉多模态多维提取规范

Agent 在接收到截图后，必须以**多模态视觉直接审阅图片**，提取以下全部维度的真实信息。若截图未展示某区块则合理标注为“无”或缺省，**绝不凭空捏造数据**：

### 1. 商铺基础信息
- **店铺名称**：完整的商户品牌与分店名称（如：`东北油边王·烧烤店(孙桥店)`、`麦悠悠·SPA·推拿(广兰路店)`）；
- **品类归属**：细分品类（如：`餐饮-烤串/烧烤`、`休闲养生-SPA/推拿`、`品质酒店-高档型`）；
- **商圈与商场**：所属商圈（如：`张江商圈`、`川沙商圈`）及所在商场或商业体（如：`张江大橘天地`、`陆悦天地`）；
- **详细地址**：截图中显示的具体路名、门牌号及楼层；
- **交通信息**：截图中若有地铁站距离或步行/驾车提示（如：`距地铁13号线张江路站1口步行450m`）务必提取；
- **营业时间**：截图中展示的营业时段（如：`17:00-次日02:00`）。

### 2. 评分与人气数据
- **综合评分**：如 `4.7分` 或 `4.0`；
- **评价总数**：如 `1752条`、`91条`；
- **细项评分**：
  - 餐饮类：`口味 4.2 ｜ 环境 4.1 ｜ 服务 4.1`；
  - 丽人/养生类：`技师 4.6 ｜ 环境 4.4 ｜ 服务 4.6`；
- **人均消费**：如 `¥77/人`、`¥149/人`；
- **官方榜单荣誉**：完整榜单全名与名次（如：`点评榜单·迪士尼烧烤烤串好评榜·第2名`、`张江商圈推拿养生销量榜第5名`）；
- **打卡与预订热度**：如 `近30天超1000人打卡`、`3000+人已订`、`年售2.3万+`、`席位紧张` 等。

### 3. 网友推荐菜 / 招牌项目（美食餐饮类必采，其他品类采核心项目）
- 提取截图中推荐菜板块列出的菜品名与推荐人数，例如：
  - `招牌大油边（23人推荐）`
  - `风干爆汁大油边（14人推荐）`
  - `五花肉（7人推荐）`

### 4. 团购/优惠信息（★核心字段，严密区分套餐与代金券）
- **团购状态**：`有` 或 `无`；
- **【到店套餐/团购项目清单】（★严禁与代金券混淆！）**：
  提取每一项具体套餐的完整数据：
  - **套餐名称**：如 `【烤验真情】烧烤单人餐`、`【筋松足畅】90分钟全身推拿+足底按摩`；
  - **团购现价**：如 `¥64`、`¥150`；
  - **门市原价**：如 `¥100`、`¥299`；
  - **折扣**：如 `6.4折`、`5.1折`；
  - **立省金额**：原价减去现价的真实差额（如：`共省36元`、`立省149元`）；
  - **销量与规则**：如 `半年售7`、`全周可用 免预约`、`随时退 过期退`；
- **【代金券专区】（★独立区隔，仅在全店消费抵扣时引用）**：
  - 代金券面值与售价（如：`100元代金券 ¥86 (8.6折，共省14元)`）；
  - 使用规则（如：`全场通用 免预约 单次可用10张`）；
- **【平台活动与神券】**：
  - 神券与补贴（如：`满100减10`、`满300减31`、`平台补贴每日开红包`、`双节同庆足浴低至6.1折起`）。

### 5. 服务设施与特色
- 截图标注的设施（如：`免费停车`、`有包间`、`7-10人桌`、`安心吃`、`共5个房间`、`免费茶水小食`）。

## 截图图片重命名与归档规范

1. **合法化命名**：提取出商铺名称后，过滤 Windows 非法字符（`\ / : * ? " < > |` 替换为下划线 `_`）；
2. **重名防覆盖**：若同名文件已存在，按 `_v2`、`_v3` 递增命名；
3. **文件夹与文件落盘**：
   - 目标文件夹：`[指定的父目录 或 YYYY-MM-DD]/[店铺名称]/`；
   - **截图物理隔离铁律**：原截图仅在 `input/`（或 `input/bak/`）目录下规范重命名归档，**严禁将 input 下面的图片复制或移动到商铺名称文件夹下**（商铺名称文件夹专用于存放小红书抓取的实拍素材与生成产物，杜绝商铺截图参与后续图片拼接）；
   - 在该文件夹内生成标准的 **`店铺关键词.txt`**。
