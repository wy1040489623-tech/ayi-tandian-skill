# 阿一商铺笔记封面 Skill (V4 年轻白领松弛网感版)

## 概述
本 Skill 专用于在大众点评笔记发布全流程中，解决“瀑布流（Feed）”场景下的高点击率（CTR）、年轻化审美与平台风控合规难题，作为 V4 统一版本体系的第 5 环节，与文案生成紧密贯通。
具备 **5 大核心优势**：
1. **内置 4 款 100% 免费可商用年轻网感字体（告别死板微软雅黑）**：
   在 Skill 同级目录下直接内置 4 款开源免费商用（SIL OFL 协议）中文字体，支持**单字体轮换与上下行异体混搭**，彻底消除传统办公黑体的生硬传单感；
2. **精准细分菜系识别（消灭笼统“特色美食/品质火锅”）**：
   自动解析《`店铺关键词.txt`》斜杠后的细分菜系与商铺全名，精准提炼 `地道绍兴菜`、`山野湖南菜`、`精致潮汕菜`、`摩登日料`、`泰国料理`、`现炒浇头面`、`杭州拌川`、`鲜鱼火锅`、`野生菌锅`、`港式打边炉`、`烤肉自助`、`鲜鳗烤肉`、`招牌小龙虾`、`推拿艾灸` 等高食欲标签；
3. **年轻白领休闲松弛感文案池**：
   摒弃老派商家口号，换装白领下班/周末聚餐的轻松口语（如 `这一口鲜掉眉毛`、`巨下饭！炫两碗`、`现炒浇头香迷糊`、`和饭搭子炫三盘`、`周末约会漂亮饭`、`滋滋冒油太香了`、`按完满血复活`）；
4. **主次字号错落层次 + 6 套奶油/多巴胺年轻配色**：
   打破“每行字一样大”的大字报土味，采用 **“顶部地标秀气引子（`tag`）+ 中部品类（`sub`）+ 底部情绪大主标（`hero`）”** 的错落字号层次，配合柔和炭黑描边与奶油亮黄、蜜桃甜橙、薄荷森系等 6 套年轻配色；
5. **全局违禁词 100% 清零 + 商铺哈希防撞词**：
   严禁出现“天花板、首选、第1名、必吃、必去、必打卡、绝了”及任何团购/价格/二维码；通过 `商铺名哈希 + note_idx` 确保同批次不同商铺、同商铺不同笔记封面 100% 不重样。

## 全局硬性红线：封面违禁词与禁令清单

> [!IMPORTANT]
> **在 V4 封面的任何文字图层中，绝对禁止出现以下内容**：
> 1. **极限词/排名词**：天花板、首选、第1名、第一、最、顶级、巅峰、极致、绝了、绝绝子、双绝、必吃、必去、必打卡、无敌、完美；
> 2. **营销导购词**：团购、超值团购、随时囤、随时退、代金券、套餐、立省、秒杀、薅羊毛；
> 3. **价格与条码**：任何具体金额数字（如 `¥64`、`立省156`）、二维码、小程序码、条形码或核销码。

## 执行指南与脚本调用

本 Skill 属于**自包含完整分发版**，驱动脚本 `store_note_cover_generator_v4.py` 与 4 款免费商用字体直接存放在本 Skill 目录下。
脚本已内置 **Pillow 依赖自动检测与自愈安装** 功能，在任何新环境下均可无感直接执行。
**视觉标准**：默认**彻底去除 30% 黑色遮罩**，保留底图 100% 原始色彩与鲜艳通透质感，依托“柔和立体深炭灰长投影 + 抗锯齿深炭黑描边”直接在原图上呈现醒目大字。

Agent 在执行封面生成时，可直接执行：

```bash
# 1. 单商铺生成 V4 封面（自动穿透识别各“笔记 X”子文件夹，默认无遮罩通透版）：
python store_note_cover_generator_v4.py --folder "[商铺文件夹绝对路径]"

# 2. 批量为父目录下所有商铺生成 V4 封面：
python store_note_cover_generator_v4.py --batch_dir "[父目录绝对路径]"
```

> 产物自动保存在目标商铺（或其“笔记 X”）目录下的 **`商铺点评笔记_封面.jpg`**。
