# 扩展位

主流程的封面默认用**本地方案**：九宫格拼图 + 字体排版。不依赖任何外部账号，开箱可用。

`plugins/` 是留给可选扩展的位置。目前规划中的只有一个：

| 扩展 | 作用 | 状态 |
| :--- | :--- | :--- |
| 生图封面 | 用 Gemini 生成更有辨识度的封面 | 独立包，默认不装 |

---

## 装上扩展之后怎么启用

主流程读一个配置项 `cover_engine`，它有两个值：

| 值 | 效果 |
| :--- | :--- |
| `local`（默认） | 用本地拼图 + 字体排版出封面 |
| `gemini` | 用扩展包生成封面 |

没装扩展时保持 `local`，代码不会去找扩展，也就不会报错。

**扩展装坏了怎么办**：把配置改回 `local`，封面立刻恢复本地方案，主流程完全不受影响。

---

## 扩展包放在哪

解开后放进本目录，例如：

```
plugins/
└── gemini-cover/
    ├── README.md
    ├── SKILL.md
    └── ...
```

具体安装和配置步骤以扩展包自带的 README 为准。
